# ArrayGrade: Working Student Grade Management Website

## Live website
The website uses HTML, CSS and JavaScript. Open `index.html` in a browser or deploy to Vercel / GitHub Pages.

## Features
Add, edit, delete, search, view grades and class statistics. The Array Explorer visualizes indexes and operations. Student data is saved in browser localStorage.

## C++ array implementation
`main.cpp` is a separate console version of the same educational application. Compile with `g++ main.cpp -o grades` and run locally. Static hosting cannot execute the C++ program.

## Deploy
Upload all files to a GitHub repository, import it into Vercel, choose framework Other, then Deploy. Alternatively enable GitHub Pages from the repository settings.
